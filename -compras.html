Funcionamiento: el Excel solo se usa una vez si quieres importar el catálogo inicial. Después el catálogo se crea/modifica/elimina desde este HTML. Los datos compartidos se guardan automáticamente en GitHub para que PC y móvil vean el mismo estado.

⏻ Reiniciar mercado

Elige el mercado que quieres poner a cero. Todas sus cantidades pasarán a 0 y se quitarán las marcas de comprado de ese mercado. Los demás mercados no se tocarán.

🔎 Buscar producto

Escribe el nombre. Si existe, podrás abrirlo y modificar todos sus datos. Si no aparece, podrás crearlo directamente con ese nombre.

Nuevo producto

Al crear un producto, elige sus mercados. Se creará con cantidad 0 y después la app lo localizará para que tú decidas la cantidad con + / −.

✎ Gestionar productos

0 seleccionados
Puedes seleccionar varios haciendo clic o arrastrando el ratón por las filas. Si arrastras cerca del borde superior/inferior, la lista se desplaza automáticamente; cuanto más cerca del borde, más rápido.

✎ Editar productos seleccionados

Solo se cambiarán los campos que elijas. Los demás datos de cada producto se conservan.

🏪 Gestionar mercados

Puedes crear mercados, cambiarles el nombre, cambiar su URL de búsqueda o eliminarlos. Al renombrar un mercado se conservan sus cantidades y marcas de comprado.

🗂 Gestionar categorías

Puedes crear categorías, renombrarlas o eliminarlas. Si renombras una categoría, todos sus productos se moverán automáticamente a la nueva.

🏠 Gestionar zonas

Las zonas sirven para recorrer la casa y decidir qué falta. Puedes crear, renombrar o eliminar zonas.

☑ Asignar productos a una zona

Selecciona varios productos y asígnalos todos a la misma zona de la casa.

🐙 Datos compartidos en GitHub

Repositorio: ykcuba-hit/Comprasweb
La app lee y guarda el estado compartido en datos.json. El token NO se publica en index.html: queda guardado solo en este navegador/dispositivo.
Importante: usa un token Fine-grained limitado únicamente al repositorio Comprasweb y con permiso Contents: Read and write. Cada dispositivo que vaya a modificar datos necesita tener el token configurado una vez.

🧾 LOG de sincronización

Este registro sirve para diagnosticar problemas entre PC y móvil. No incluye el token de GitHub. Cuando ocurra un fallo, pulsa Descargar LOG y súbemelo.
